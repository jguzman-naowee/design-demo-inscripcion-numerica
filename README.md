# design-demo-inscripcion-numerica

Demo navegable de la fase de inscripción numérica de los XXIII Juegos Deportivos Nacionales (Córdoba–Sucre 2027). Tres roles: Delegado, Admin de plataforma y Comité organizador, con las 17 historias de usuario (HU-IN-01 a 17) dentro de la interfaz.

Es un prototipo de diseño: datos de ejemplo salvo los del consolidado de delegaciones. Los correos están enmascarados.

Entrada: `index.html`.
